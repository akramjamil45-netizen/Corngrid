SECURITY

Credential handling

  • The SMTP password is encrypted at rest with AES-256-GCM and is never returned by the API.
  • Only an authenticated administrator can read, update, test, or use these settings.
  • Every email request is validated, rate-limited, and recorded in the email activity log.
  • Bulk announcements are queued per recipient with retry and backoff.
  • “Sent” records SMTP acceptance only. CornGrid does not claim inbox delivery.

After changing the host, port, or encryption, run Test SMTP connection before sending a campaign.
