MT5 SETUP & TROUBLESHOOTING

WebRequest Configuration Guide

To enable your MT5 Expert Advisor to link and synchronize trading data with this dashboard, allow WebRequest in MetaTrader 5:

1. Enable WebRequest in MT5 Open MT5 → Tools → Options (Ctrl+O) → Expert Advisors → Check "Allow WebRequest for listed URL".
2. Add Dashboard URL Add this exact URL: https://corngrid.com
3. Enter Pairing Code Generate a code above and paste it into the InpDashboardPairingCode EA input parameter.
Common MT5 Error Codes & Solutions (Ralat Lazim)
  • MT5 Error 4014 (ERR_WEBREQUEST_NOT_ALLOWED): https://corngrid.com is missing from MT5's Allowed URLs list. Add it under Tools → Options → Expert Advisors.
  • HTTP Error 400: The pairing code has expired (codes expire after 10 minutes) or has already been used. Click "Generate pairing code" above for a new code.
  • HTTP Error 409: This MT5 account number and broker server is already linked to your profile.
  • Status Stays Offline: Ensure the "Algo Trading" button is active (green) in MT5 and your terminal remains connected to your broker.

STATUS DEFINITIONS

Connection states

Online

A valid authenticated heartbeat was received within the configured timeout.

Offline

A previously linked EA has not sent a heartbeat within the configured timeout.

Waiting for data

The account is linked but has not yet sent its first heartbeat.

Privacy

Portfolio visibility

Choose which linked trading accounts appear on your public portfolio. Only selected accounts and their portfolio data are shown publicly. You can keep everything private or revoke public access at any time.

Public data shown

For each selected account, public pages show its masked account identifier, account summary, open positions and recent trade details. They never show your email, broker server, full account number, ticket or deal identifiers, or trading credentials. Accounts you do not select remain private.

Data collected

When you link an EA, CornGrid can store the MT5 account identifier, broker/server, account currency, balance and equity snapshots, open positions, imported trade deals, EA version, and heartbeat timestamps sent by that installation.

How data is used

This information is used to display account monitoring and portfolio analytics to the authenticated owner of the linked account. No MT5 trading password is requested or stored.

Retention and export

Linked account data remains stored until the account is unlinked or the applicable account-retention process removes it. Contact support for a personal data export or deletion request.
