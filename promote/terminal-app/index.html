Getting Started

Connected in Four Steps

From a fresh account to a live terminal in minutes. The web portal needs no installation — only the Android app is downloaded separately.

  1. 01

    Create your CornGrid account

    Register once to unlock the Trading Terminal Portal, the Android app and the CornGrid community feed. It is the same account on every device.

  2. 02

    Generate a pairing code

    Open MT5 Accounts in the terminal and generate a one-time pairing code. Codes expire after 10 minutes and can only be used once.

  3. 03

    Link your CornGrid EA

    Paste the code into the InpDashboardPairingCode parameter of CornGrid EA in MetaTrader 5, then allow WebRequest for https://corngrid.com under Tools → Options → Expert Advisors.

  4. 04

    Trade from any device

    Your account turns online in the terminal after the first heartbeat. Install the Android app to follow the same dashboard, positions and feed in your pocket.
