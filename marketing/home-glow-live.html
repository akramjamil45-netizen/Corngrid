MEET CORNGRID SANDBOX

Your Trading Environment, Managed by CornGrid.

CornGrid Sandbox is a managed MetaTrader 5 execution environment operated through CornGrid Infrastructure. Each sandbox enables automated strategies to run through an assigned MT5 terminal without requiring users to manually install and maintain their trading terminals.

Current separation uses individual terminal folders and processes on a node. It is not full VM isolation and does not provide a dedicated IP per sandbox. Availability depends on node capacity and subscription eligibility.

ANSWERS YOU NEED

Clarity before you begin.

What is CornGrid Infrastructure?+

A technology platform for managing supported MT5 execution environments, subscriptions, strategies and sandboxes from one dashboard.

What is a CornGrid Sandbox?+

An assigned MT5 terminal with separate folders and processes on a CornGrid node. It is not a full VM and does not necessarily have a unique IP.

Do I need my own VPS?+

Not for the supported hosted workflow. CornGrid manages the execution node, subject to available capacity.

Does CornGrid guarantee trading profits?+

No. Automated trading can cause losses, including loss of capital. Past performance does not guarantee future results.

How does the subscription system work?+

Sign in to view current plans. Select a plan, pay via DuitNow and submit proof for administrator review. Access follows approval and the plan’s validity period.

How connection information is handled

Use the dashboard form over HTTPS for MT5 details. The backend stores sandbox credentials encrypted with AES-256-GCM and restricts access through account and administrator authentication. Authorized agents require connection details to run MT5; terminal configuration files on the node also contain those details. Folder separation is not a guarantee of complete security.
